# 金融热词演变分析：从"十四五"到"十五五"

> 覆盖 2021—2026 年，截至 2026-09。配套词库见 `finradar/data/glossary/`，
> 用 `finradar term <词>` 查任一词条的完整解析。

---

## 一、一句话结论

**"十四五"的关键词是"防"，"十五五"的关键词是"建"。**

- 2021—2023：主线是 *防范化解重大金融风险* + *全面注册制*，
  政策语言里高频出现"整治""规范""化解""出清"。这是**补短板、治乱象**的阶段。
- 2023 年 10 月中央金融工作会议是分水岭：**金融强国**、**五篇大文章**、
  **中央银行制度** 三个总纲性提法同时出现。
- 2024—2026：主线转为 *建制度、造工具、引长钱*，
  高频词变成"完善""构建""培育""耐心资本""科技板"。这是**建体系**的阶段。

判断一个新提法属于哪一阶段，看它的动词：**"整治/规范/化解"是十四五语法，
"完善/构建/培育"是十五五语法。** 这在面试里是很有效的框架句。

## 二、五条演变主线

### 主线 1：货币政策——从"数量"到"价格"

| 时间 | 事件 | 词汇变化 |
|---|---|---|
| 2019 | LPR 改革 | MLF 成为定价锚 |
| 2024.06 | 陆家嘴论坛明确**7 天期逆回购利率**为主要政策利率 | 定价锚换人 |
| 2024.07 | OMO 改为**固定利率、数量招标**；MLF 改为**多重价位中标** | MLF 淡出政策利率 |
| 2024.10 | 创设**买断式逆回购**；重启**国债买卖** | 基础货币投放渠道扩容 |
| 2024.12 | 基调由"稳健"改为**适度宽松**（2011 年来首次） | 五档基调换档 |
| 2026 | "综合融资成本低位运行"、首提**促进物价合理回升** | 新增反通缩之锚 |
| 2026.08 | 央行《"十五五"改革发展规划》：**加快完善中央银行制度** | 制度化收口 |

**分析**：这条线的实质是**淡化 M2/社融增速目标、强化利率信号**。
很多同学的知识还停在 2019 年的 LPR 叙事，一开口说"降息就是降 MLF"就露怯了。
2026 年新增的"物价合理回升"是最好的加分点——它把货币政策的目标函数从
"稳增长"扩展到"反通缩"，逻辑是**名义利率减通胀才是实际利率**。

**面试用法**：被问"你怎么看货币政策"，先说档位（适度宽松，2024 年 12 月转向），
再说锚（7 天逆回购，不是 MLF），最后说 2026 新变化（物价回升写进考量）。

### 主线 2：资本市场——从"注册制"到"投融资平衡"

| 时间 | 事件 |
|---|---|
| 2023.02 | 全面注册制落地 |
| 2024.04 | 新**"国九条"**（第三个），形成 **1+N** 体系 |
| 2024.06 | **科创板八条** |
| 2024.09 | **并购六条**；中央金融办、证监会《推动中长期资金入市指导意见》 |
| 2024.10 | 央行创设 **SFISF**（互换便利）+ **股票回购增持再贷款** |
| 2024.11 | 《上市公司监管指引第 10 号——市值管理》 |
| 2025.01 | 六部委《推动中长期资金入市实施方案》（**险资新增保费 30% 投 A 股**） |
| 2025.05 | 《推动公募基金高质量发展行动方案》（**浮动费率 + 三年考核权重≥80%**） |
| 2025.06 | 科创板改革 **"1+6"**（科创成长层、扩大第五套标准适用） |
| 2026.01 | 《公开募集证券投资基金销售费用管理规定》施行 |

**分析**：三个转向叠在一起——

1. **从"重融资"到"投融资平衡"**：一端严把入口、加大退市，
   另一端强制分红、规范减持、引长钱。
2. **从 IPO 到并购**：IPO 阶段性收紧后，一级市场退出压力被"并购六条"承接，
   投行的能力要求从**合规与流程**转向**交易设计与产业理解**。
3. **从主动到被动**：费率改革 + 汇金增持宽基 ETF，2024 年被动指数基金
   持股规模首次超过主动权益。

**面试用法**：这三条转向都能用同一句话收尾——**"制度在把回报机制修回来"**。

### 主线 3：科技金融——债权工具怎么承担股权风险

这是"五篇大文章"里最难、也最出彩的一篇。核心矛盾：
**科技企业轻资产、高失败率、收益呈幂律分布；而信贷是固定收益、要覆盖尾部风险。**
用债权工具承担股权风险，必然亏。

政策给了三条解：

| 路径 | 工具 | 关键突破 |
|---|---|---|
| 让股权工具进来 | **银行 AIC 股权投资试点** | 2024.09 扩围至 18 城；表内资金投资比例 4%→10%；单只基金 20%→30% |
| 让债券市场分层 | **科技创新债券**（2025.05） | 首次把**股权投资机构（VC/PE）**纳入发行主体 |
| 让风险被分担 | 央行低成本再贷款 + 政府性担保 + 债券市场**"科技板"** | 央行"十五五"规划明确建设 |

**分析**：注意"科创债"的真正突破**不是**"给科技企业发债"，
而是**让 VC/PE 能发债募资**——这解决的是耐心资本的**来源**问题，
而不是科技企业的融资问题。能讲清这一层，明显高于平均水平。

### 主线 4：对外开放——"宽进慎出"的不对称结构

这是最容易答错、也最容易加分的一类，因为它有明确的**额度事实**：

| 制度 | 方向 | 额度状态 |
|---|---|---|
| **QFII / RQFII**（合格境外投资者） | 流入 | **额度已于 2019-09-10 取消**；2020-11 两制度合并 |
| **QDII** | 流出 | 仍按机构逐笔核准；截至 2026-06-30 累计 **1761.69 亿美元** |
| QDLP / QDIE | 流出（另类） | 地方试点额度，规模远小 |
| QFLP | 流入（股权） | 地方试点 |
| 沪深港通 / 债券通 / 互换通 / 跨境理财通 | 双向 | **不占用 QDII/QFI 额度**，每日或年度额度管理 |

**分析**：把这张表连起来，能得出一个很有说服力的判断：
**流入方向已无额度，流出方向仍逐笔核准——这正是"宽进慎出"的资本项目管理取向，
和人民币汇率与国际收支的压力方向一致。** QDII 额度的发放节奏本身就是
一个成本低、可逆的外汇逆周期调节工具。

同时，互联互通之所以被优先推进，是因为它**"闭环 + 本币结算"**——
资金跨境但净额清算、原路返回，监管可测可控。理解了这一点，
2024—2026 年的开放动作（互换通、跨境理财通 2.0 把个人额度从 100 万提到 300 万、
ETF 通扩容、CIPS 新规 2026-02 施行、数字人民币国际运营中心 2026-06 首批 26 家直参）
就都能串成一条线。

### 主线 5：新变量——数字化与"反内卷"

2025—2026 年新冒出来、词库里必须补的两组词：

**（1）稳定币 / RWA / 代币化**

- 香港《稳定币条例》2025-08-01 生效，实行**发牌制**，要求储备 100% 足额、
  高质量流动、独立托管、按面值赎回。
- 美国 2025 年通过稳定币立法。
- **内地立场未变**：虚拟货币相关业务活动属非法金融活动；监管多次提示
  以"RWA 代币化"为名的非法集资风险。
- 判断路径：**内地以数字人民币为主，香港作为离岸试验场**；
  真正合规的方向是受监管机构主导的**代币化存款与代币化基金份额**。

**（2）反内卷 / 促进物价合理回升**

- 2024-07 政治局会议首提"防止'内卷式'恶性竞争"，2025 年升级为综合整治。
- 它和"物价合理回升"是**一体两面**：PPI 长期为负，很大程度上不是需求不行，
  而是产能重复建设、价格战。
- 与 2016 年供给侧改革的关键差异：那轮**行政去产能、上游国企为主**，见效快；
  这轮对象是光伏、锂电、汽车、电商等**民企与新兴行业**，主要靠标准与法治，
  节奏更慢、更依赖需求端配合。

## 四、高频考法与判分点

面试官通常按四个层次递进，每一层的分数不同：

1. **是什么**（及格）——能准确说出名称、时点、发文主体。
   *风险：名称说错一个字就掉档，比如"五篇大文章"漏掉"养老金融"。*
2. **为什么**（良好）——能说清它要解决什么矛盾。
   *例：中长期资金入市解决的不是"钱不够"，而是"长钱短考"。*
3. **所以呢**（优秀）——能给出传导链和受影响主体。
   *例：化债 → 高息城投换低息政府债 → 银行资产质量改善但收益率下降 → 资产荒。*
4. **你怎么看**（拔尖）——能指出局限、给出条件判断，而不是背单向结论。
   *例："降准利好债市"是半句话，完整的是"要先看是否已被 price in，
   再看长端受供给冲击的程度"。*

**这份词库的每个条目都按 1→4 层写好了**：`definition` 是第 1 层，
`why_hot` 是第 2 层，`exam_points` 与 `interview_answer` 是第 3 层，
`followups` 是第 4 层。

## 六、还在观察的词（尚未成熟，但值得留意）

- **债券市场"科技板"** 的具体制度安排（发行、披露、适当性、做市）
- **离岸人民币稳定币** 在香港监管框架下的实际落地
- **AIC 扩容后的退出机制**与尽职免责细则
- **浮动费率基金**的业绩比较基准选择规范
- **十五五规划纲要**金融章节的部门配套细则（各部委陆续印发中）
