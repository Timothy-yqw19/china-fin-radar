## 二、项目在做什么

一句话：**左手抓政策新闻，右手接秋招考点，中间用打分和热词把两者连起来。**

```
官方政策站点 ─┐
财经快讯     ─┼─▶ 政策相关度打分 ─▶ 热词榜 ─▶ 日报(MD/HTML)
AkShare      ─┘                      │
                                      └─▶ 热词库(考点+答法) ─▶ 刷题/错题本
```

### 代码规模

- Python 约 **2,921 行**（11 个抓取器 + 打分 + 报告 + 知识库 + CLI）
- 数据 YAML 约 **3,492 行**（词库 + 题库）
- 测试 **120 个，全部通过**；`ruff` 无告警

### 三大模块

**1. 抓取（`finradar/crawlers/`）—— 11 个数据源**

| 类型 | 数据源 | 通道 |
|---|---|---|
| 官方政策 | 中国政府网政策文件库、证监会、金融监管总局 | JSON 接口 |
| 官方政策 | 中国人民银行 | HTML，失败自动回退政府网 |
| 官方政策 | 国家外汇管理局 | HTML |
| 快讯 | 东方财富 7×24、财经早餐、财联社电报、同花顺、新浪 | JSON 接口 |
| 兜底+宏观 | AkShare | Python 包 |

`config/sources.yaml` 支持**零代码扩展**——加一个政务站点只要填 selector。

**2. 分析（`finradar/analysis/`）**

政策相关度打分（0–100），规则写在 `config/keywords.yaml`：

- 六类关键词各自加权（政策动作 / 发文主体 / 货币 / 资本市场 / 银行保险 / 对外开放 / 主题）
- 同类多次命中**递减计分**，单类封顶 2 倍权重 —— 防止堆砌关键词刷分
- **协同加分**：只有"官方主体 + 具体领域"同时命中才算真政策新闻
- 噪音降权：涨停、龙虎榜、概念股、午评直接扣分
- 附一句**传导逻辑**，例如：化债 → 高息城投换低息政府债 → 银行资产质量改善但收益率下降 → 加剧"资产荒"

演示数据下的实际排序：

```
[100.0] 证监会   证监会就修订《上市公司重大资产重组管理办法》公开征求意见
[ 76.0] 政府网   国务院办公厅关于做好金融"五篇大文章"的指导意见
[ 62.0] 财联社   央行行长：继续实施适度宽松的货币政策，促进物价合理回升
[  0.0] 快讯     午评：三大指数集体高开，AI概念股涨停，主力资金净流入
```

**3. 知识库（`finradar/data/`）**

**46 个热词**，六大分类（其中 25 个标为★★★★★，2026 秋招高频）：

| 分类 | 词数 | 代表词条 |
|---|---|---|
| 宏观与货币政策 | 10 | 金融强国、五篇大文章、适度宽松货币政策、中央银行制度、政策利率体系、新质生产力、反内卷、一揽子化债、十五五规划 |
| 资本市场与证券行业 | 10 | 新"国九条"、中长期资金入市、公募高质量发展改革、ETF被动化、并购六条、科创板"1+6"、市值管理、科创债、公募REITs |
| 对外开放与跨境投融资 | 7 | **QDII**、**QFII/RQFII**、QDLP/QFLP、互联互通（沪深港通/债券通/互换通/跨境理财通）、人民币国际化、CIPS |
| 银行与保险 | 7 | 净息差、资本新规、银行AIC、险资长期投资试点、个人养老金、房地产新模式、理财净值化 |
| 金融风险与监管体系 | 7 | 一行一局一会、穿透式监管、三大重点领域风险、存款保险、新反洗钱法、投资者保护、程序化交易监管 |

每条的字段结构：定义 → 出处 → 为什么热 → **考点清单** → **60–90 秒口语化答法** → 数据快照（带 as-of）→ **追问及应答** → 关联词。

**51 道题**，六大板块（简答 37 / 多选 6 / 情景 5 / 单选 3），每题含考点、标准答案、口语化表达、追问延伸。全库共 **62 组追问应答**。

## 三、达到了什么

**1. 把"政策"和"考点"真正打通了**
不是两个独立的东西堆在一起：新闻打分命中的热词，直接指向词库里同名的考点条目，日报里的"传导逻辑"就是面试被追问"所以呢"时的答案。

**2. 答案写成了能说出口的话**
每个词条和每道题都有单独的 `spoken` / `interview_answer` 字段，控制在 60–90 秒，是口语不是书面语。这是和市面上"金融名词解释"最大的区别。

**3. 对时效性做了结构化处理**
所有数字带 `as_of` 标注（如 QDII 额度截至 2026-06-30 为 1761.69 亿美元）；`finradar facts` 现拉 LPR/M2/CPI/国债收益率；`finradar hot --discover` 能从新闻里捞出词库还没收录的新提法。

**4. 抓了几个真正有区分度的考点**
- QFII 额度**早在 2019 年就取消了**——这是最容易答错的一题
- "流入无额度、流出有额度"的**不对称结构**，反映"宽进慎出"的资本项目管理取向
- 科创债的突破**不是**给科技企业发债，而是让 VC/PE 能发债募资
- 中长期资金入市的核心矛盾是"**长钱短考**"，不是"钱不够"
- 现在说"降息"指的是 **7 天逆回购**，不是 MLF

**5. 工程上是能维护的**
120 个测试里有两组守护：一组逐条校验词库题库的**字段完整性**（每个词必须有考点和口语化答法，每道选择题的正确项必须在选项里），防止后续补内容写漏；另一组用**离线样本**验证各站点解析逻辑，接口改版时会先失败提示。配了 GitHub Actions CI。

**6. 三种交付形态都在**
命令行（`finradar quiz`）、可打印文档（Markdown）、手机能开的网页（Artifact）。

## 四、未达到什么

这部分请认真看，直接决定你用的时候会踩什么坑。

### ⚠️ 1. 联网抓取从未在真实网络下跑通

构建环境的出口被限制，**所有境内站点都超时**。我只能用离线样本测解析逻辑（`tests/test_parsers.py` 存了各站点真实响应的字段骨架，接口地址和参数是从 akshare 源码和浏览器实际请求里核对的）。

**这意味着**：第一次在你本机跑 `finradar crawl` 时，可能有若干源直接挂。`finradar doctor` 会逐源报告哪个通哪个不通，并给出修复方向，但修 selector 这件事要你自己做。

### ⚠️ 2. 央行（PBC）和外汇局（SAFE）的 HTML 解析是**盲写**的

这两个站点没有公开 JSON 接口，我写的是 BeautifulSoup 选择器，但**没有拿到真实页面验证过**。央行还有 WAF（`wzws` 风控），直连 requests 大概率 403——所以我做了自动回退到政府网政策库的兜底，但回退路径同样未实测。

### ⚠️ 3. `config/sources.yaml` 里的四个源（财政部、发改委、统计局、上交所）完全没验证

那是**配置模板示例**，selector 是猜的。要用得自己打开页面对一遍。

### ⚠️ 4. AkShare 通道没装过

`akshare` 是可选依赖，构建环境装不上（网络）。`finradar facts` 的接口名和签名是从 akshare 1.18.94 源码里核对的，但**没有真正调用过一次**。

### ⚠️ 5. GitHub 没推上去

本会话的 GitHub 凭据注入失败，我没法替你建仓库、推代码。仓库本身初始化好了、有 2 次提交、CI 配置齐全，你三条命令就能上去（见 README）。

### ⚠️ 6. 题库规模偏小

51 道题对秋招来说是**框架够用、量不够刷**。真实笔试一套就四五十题。现在的定位是"考点索引"而不是"题海"。

### ⚠️ 7. 内容准确性有边界

- 我的训练数据截止 **2026 年 5 月**，2026 年 5 月之后的事实靠联网检索补的，有遗漏风险。
- 只有 **2 个词条**带完整数据快照（QDII、适度宽松货币政策），其余靠 `finradar facts` 现拉。
- 政策解读是整理，不是权威口径，**以官方原文为准**。
- 有些数字（如康美案 24.59 亿、化债 12 万亿的三段构成）来自公开报道，面试前值得自己核一遍。

### ⚠️ 8. 没有做的事

- 没有反爬对抗（代理池、验证码、浏览器渲染）——政务站 WAF 强化就抓不到
- 没有做增量抓取的时间游标，每次是全量拉+去重
- 没有全文抓取，只抓标题和摘要（所以打分只基于标题+摘要）
- 词库更新还是手写 YAML，`--discover` 只能提示新词，不能自动生成词条
- 网页版的刷题进度依赖 Artifact 的 db 能力，如果不可用会退回 localStorage（单设备）

## 五、建议的下一步

按性价比排序：

1. **先跑 `finradar doctor`**，把真实能通的源摸清楚，修掉挂掉的 selector。这是让整个项目从"能演示"变成"能用"的唯一一步。
2. **推到 GitHub**，把 CI 跑起来。
3. **补题库**：按你实际投的机构方向加题（比如你投固收就重点补 `02_fixed_income.yaml`）。格式照着现有的写，测试会校验字段完整性。
4. **每周跑一次 `finradar hot --days 7 --discover`**，把新出现的提法补进词库——这才是这个项目相对于静态资料的真正价值。
5. 面试前一晚：`finradar report --days 7 --min-score 60`，只看这一页。
