## 0. 三十秒了解

**面试对象**：银行总行的「投行与金融市场」条线（招行总行管培按方向分开招、分开面，
公司金融 / 零售金融 / 资产管理 / **投行与金融市场** / FinTech 五个方向，
报的方向不同后面面试内容不同 `【面经】`）。

**这条线包含什么**：

| 部门 | 干什么 | 面试官可能问什么 |
|---|---|---|
| 投资银行部 | 债券承销（银行间债务融资工具、公司债）、并购、结构化融资、ABS | 承销流程、尽调、包销风险、信用分析 |
| 金融市场部 | 债券投资与交易、外汇、贵金属、衍生品、同业与流动性 | 久期、收益率曲线、降准降息传导、做市与头寸 |
| 资产管理 / 理财子 | 理财产品设计、固收+、委外 | 净值化、资产配置、回撤控制 |
| 资产托管部 | 托管、估值、外包 | 托管链条、估值差错处理 |
| 金融机构部 | 同业客户（银行/保险/券商/基金） | 同业存单、同业授信、机构销售 |

**四关**（招行总行，两个年份的真实版本，见 §2）：

| 关卡 | 形式 | 真正在考什么 |
|---|---|---|
| 一面 | 16 人一组，3 分钟读题，每人一句话谈时事热点 → **1 分钟英文自我介绍 + 2 分钟陈述** `【面经】` | 表达、临场、英语能不能听懂 |
| 二面 | 无领导小组讨论。三种形态轮换：**游戏型**、**分组对抗辩论（4v4/5v5）**、**排序/方案题** `【面经】` | 会不会推动讨论、有没有结构、有没有团队感 |
| 三面 | 2V1 简历 + 动机面 `【面经】` | 动机真不真、简历经不经得起追问、轮岗能不能接受 |
| 四面 | **晚 8 点发课题、次日早 6 点前交**，7 分钟 PPT 展示 `【面经】` | 12 小时内能不能独立产出一个有结构的判断 |
| 签约 | 管培 2+3+N，前两年分行轮岗（北上广深、武汉、南京、天津、重庆、苏州等） `【面经】` | — |

**三个不能说的话**：①「银行稳定、轻松」；②「想做量化/算法，银行是先过渡」；
③在轮岗、部门、城市上挑三拣四（可以表达偏好，但先说接受）。

## 1. 为什么这条线值得单独准备

它和券商投行、纯买方固收都不一样：银行是「商行 + 投行」，既有承销牌照，
又有资产负债表和客户基础，能提供「承销 + 投资 + 托管 + 结算」的一揽子方案。
所以面试官考察的复合度更高：

1. **懂市场**：利率、信用、汇率、流动性的基本判断（对应题库 `ibfm-001` ~ `ibfm-007`）；
2. **懂业务链条**：承销怎么走、ABS 怎么分层、FTP 怎么定价（`ibfm-008` ~ `ibfm-015`）；
3. **懂风险和合规**：包销风险、IRRBB、LCR/NSFR、适当性红线（`ibfm-009/012/013/016`）；
4. **能落地**：群面推进、限时课题、结构化表达（`iv-001` ~ `iv-010`）。

> 判断标准很简单：**你讲的东西能不能落到"头寸、定价、客户、风险"四个词上**。
> 只讲概念不讲这四个词的答案，在这条线上拿不到高分。

## 2. 面试流程：两个年份的真实版本

### 2.1 版本 A（2022 届，最完整）`【面经】`

1. 简历筛选（专业不限，有海归倾向）
2. **一面**：16 人一组随机抽签，入场 3 分钟读题，每人面前一张纸写一句话 →
   按顺序 **1 分钟英文自我介绍 + 2 分钟陈述**（谈时事热点）
3. **笔试**：全国统一。30 分钟英文（近义词辨析 + 阅读）+ 行测 +
   趣味测试（找不同、找移动小球）+ 心理测试，**不考金融专业知识**
4. **二面**：无领导。公司金融方向是 8 人 4v4 辩论；零售方向是 12 人拼图游戏
5. **三面**：二面在场的两位面试官问简历与动机
6. **终面**：案例分析 PPT 7 分钟展示，**前一天晚 6 点发题，12 小时内做完**
7. 签约：2+3+N

### 2.2 版本 B（2025 届，投行与金融市场条线复盘）`【面经】`

1. **二面**：无领导小组讨论（**游戏**）——每人 3 张牌，不知道牌面大小，另有 1–2 张信息牌；
   按顺序描述并轮流出牌，**全场总和要无限接近目标分数**
2. **三面**：2V1，简历 + 动机
3. **四面**：**晚 8 点发课题，次日早 6 点前交**；PPT 展示 + 简历/动机追问
   （面试官基本不问课题内容，重点看 **PPT 框架、内容充实度、演讲自信**）

> **结论**：二面形式在「游戏 / 辩论 / 排序方案」之间轮换；三面是简历动机；四面是限时课题。
> **淘汰主要发生在二面和四面**，准备资源要按这个顺序投。

## 3. 第一关：一面（时事热点一句话 + 英文自我介绍 + 2 分钟陈述）

**真题** `【面经】`：佛系青年、固化思维、对抖音的看法。
`【推断】` 近年高频候选：AI 与银行、低利率环境、养老金融、地方债务、绿色金融、
消费提振、数字人民币。

**时间分配**（每人约 3 分钟）：0–1 分钟英文自我介绍（提前背到 45 秒，因为紧张会变慢）；
1–3 分钟中文陈述。

**热点题四步（2 分钟版）**：
> ① 一句话定性（10 秒）→ ② 机制/原因（40 秒，2 点）→ ③ 影响与风险（30 秒，分主体：
> 个人/机构/监管）→ ④ 落到银行业 + 一句自己的判断（30 秒）

**示例（抽到「AI 与银行」）**：

> 我的判断是：AI 不会替代银行人，但会**重新分配银行人的时间**。
> 原因有两点：一是银行大量成本压在重复性作业上（客服、单据、报表），AI 在这类任务上的
> 边际成本几乎为零；二是银行的真正稀缺资源是**信任和判断**，这两件事短期内 AI 给不了。
> 风险也清楚：模型的黑箱、数据合规、以及「算法歧视」在信贷里会被监管追问，
> 所以银行上 AI 一定是「人机协同 + 可解释」。
> 对招行来说，手机银行承载了绝大多数非现金零售业务，AI 让「因您而变」从口号变成千人千面。
> 我个人想做的，是**懂业务又会用模型**的那类人，而不是只调参的人。

> ⚠️ 英文部分不要追求难词，追求「听得懂、有结构、不卡」。面试官的要求就是「能听懂」。

## 4. 第二关：无领导小组讨论（三种形态，逐一说）

### 4.1 形态一：游戏型（信息不对称 + 共同目标）`【面经】`

**真题**：每人 3 张牌，不知道牌面大小，另有 1–2 张信息牌；按顺序描述并轮流出牌，
全场总和要无限接近目标分数。

**这类题考的不是「赢」，是「协作与信息整合」**：

- 目标是**集体最优**，不是个人最优 → 抢着出大牌会让总和爆掉；
- 信息是**分散且私有**的 → 核心动作是**主动公开信息、建立共同的计算口径**；
- 轮次是固定的 → 需要有人**记账**。

**打法（30 秒开场就能定调）**：

> 「这个题的关键是我们能不能把各自知道的信息拼起来，算出一个共同的目标区间。
> 我建议先花 2 分钟让每个人把**你确定知道的信息**说出来，我来做记录和累加；
> 然后我们再决定出牌顺序。目标不是谁出得多，是总和最接近目标。」

**要抢的角色**：**记录者 + 计算者**。不需要抢话，只要说「我算一下」，全场都会看你的白板。
（完整方法见题库 `iv-004`）

### 4.2 形态二：分组对抗辩论（4v4 / 5v5，现在最主流）

**流程**（真实复盘拼出来的标准版）：组内讨论 8–15 分钟 → 每组 1 人总结陈述 2–3 分钟 →
双方互辩 10 分钟（A 组每次问一个问题，B 组最多 3 人回答，然后互换）→ 3 分钟结辩。

**真题** `【面经】`：

- 电子竞技是否应该纳入奥运会项目（招行总行，8 人 4v4）
- 梦想是否会被现实打败（招行总行，同场另一组）
- 应届生职业生涯初期，应优先选择高薪资，还是更有发展潜力的平台（招行广州分行，2025）

**打赢的关键不是观点，是分工**：
> 组内讨论一开始就分：**1 辩立论、2 辩质询（专攻对方定义）、3 辩数据与机制、4 辩结辩**。
> 数据能力强的人最适合 3 辩或 1 辩——因为你能给出别人给不出的数字和传导链条。
> （立论/自由辩论/结辩的完整模板见题库 `iv-003`）

### 4.3 形态三：排序 / 方案题（分行最高频）

**真题** `【面经】`（招行深圳分行 2026）：

- 7 条银行数字化风控建议排序：①智能风控体系 ②数据安全分级 ③网络安全设施 ④风控合规制度
  ⑤风控人才 ⑥算法模型全生命周期管理 ⑦跨机构协同
  → 参考排序 **②＞③＞①＞⑥＞④＞⑤＞⑦**（安全底座 → 核心能力 → 制度与人）
- 8 个城市建设指标选 3 个（通勤、绿地、房价收入比、医疗、创业政策、夜生活、教育、治安）
  → 参考 **创业政策扶持 ＞ 房价收入比 ＞ 医疗资源均衡**（先讲城市定位，再讲「为什么不选夜生活和绿地」）

**方案题真题** `【面经】`：养老社区建设/升级方案、手机银行 App 适老化改造、
绿色金融产品设计、与知名品牌联名营销、小微企业宣传企划（**分组对抗式**）、
银行如何改善适老化服务。

框架与话术见题库 `iv-001`（排序）、`iv-002`（方案）。

## 5. 第三关：2V1 简历与动机面（真题清单）

| 真题 `【面经】` | 考察点 | 答题要点 |
|---|---|---|
| 你最近一段实习做了什么？ | 简历真实性、表达 | 60–75 秒讲三件事 + 结果，别念简历；准备好 2–3 层追问 |
| **为什么之前没有银行的实习？** | 压力题、诚实度 | 不辩解：承认短板 → 可迁移能力 → 已做的补课动作 → 入职后愿从轮岗补 |
| 如果轮岗后去不了你最想去的部门，怎么办？ | 稳定性、动机 | 无条件接受 → 轮岗对目标岗位的具体价值 → 长期路径（`iv-007`） |
| 为什么不去 FinTech / 为什么不做算法？ | 动机纯度 | 不说对方不好；讲「产出差异」：模型指标 vs 头寸/定价/客户方案 |
| 四大行给你 offer，你会拒绝招行吗？ | 意向排序 | 明确优先 + 给条线理由（市场化程度、业务完整度、决策链条） |
| 你为什么选择金融行业？ | 动机 | 能力匹配 → 反馈快（市场每天打分）→ 可积累 |
| 你的职业规划？ | 自我认知 | 1 年跑通一条业务线 / 3 年独立判断 / 5 年既懂定价又懂客户与产品 |

> 通用原则：这关的评分点是 **「情绪稳定 + 有判断 + 有行动」**，
> 不是「理由多完美」。压力题的正确姿势是：承认事实 → 给判断 → 说下一步。

## 6. 第四关：限时课题 + PPT（12 小时，真正拉开差距的一关）

**流程** `【面经】`：晚 8 点发题 → 次日早 6 点前发到邮箱 → 现场 7 分钟展示。
**关键事实**：面试官**不一定问课题内容**，重点看 **PPT 框架、内容充实度、演讲自信**。
这意味着：**结构 > 深度，完成度 > 完美**。

### 12 小时时间切分

| 时段 | 动作 | 产出 |
|---|---|---|
| 20:00–20:30 | 读题、拆问题、定「一句话结论」 | 一句话论点 |
| 20:30–21:00 | 搭 PPT 目录（10 页），先定结构 | 目录 |
| 21:00–01:00 | 找数据、做测算/对比 | 图表 3–5 张 |
| 01:00–03:00 | 填内容、写结论页 | 初稿 |
| 03:00–04:30 | 打磨图表与措辞，砍掉一半文字 | 定稿 |
| 04:30–05:30 | 出声演练 3 遍，掐 7 分钟 | 讲稿 |
| 05:30–06:00 | 导出、检查、发送（留 30 分钟 buffer） | 提交 |

### 10 页 PPT 万能骨架

1. 封面（题目 + 一句话结论）
2. **结论摘要**（面试官只看这一页：3 条结论 + 3 个理由）
3. 问题定义与分析框架
4. 市场/行业背景（2–3 张关键数据）
5. 核心分析 ①（数据与测算）
6. 核心分析 ②（对比/敏感性/情景）
7. 方案或判断（明确、可执行）
8. 风险与情景分析（**最加分**：如果变量反过来会怎样）
9. 落地路径与关键节点（谁、什么时候、要什么资源）
10. 附录（数据来源与假设，**一定要有**）

### 这类线可能的课题类型 `【推断】`

| 类型 | 例子 | 答题抓手 |
|---|---|---|
| 信用与承销 | 给一家企业，判断能不能承销它的债 | 行业→经营→财务→治理→增信→区域（`ibfm-018`） |
| 市场判断 | 未来 6 个月 10 年国债走势与交易策略 | 基本面+资金面+供需+外部+情绪（`ibfm-002`） |
| 产品设计 | 设计一款绿色/科创主题债券或 ABS | 底层资产→结构→增信→定价→投资者（`ibfm-010`） |
| 客户方案 | 给某类客户做综合金融服务方案 | 需求分层→产品组合→风控→收益 |
| 资产负债 | 低利率环境下如何管理息差与久期 | 资产端/负债端/表外/对冲（`ibfm-020`） |

> 别人做课题靠 PPT 堆砌，你能放**真实测算**（久期、敏感性、情景回测）——一张自己算的表，
> 胜过十页文字。

> 准备时「辩论能力」的权重不要低于「排序框架」。

### 8.1 辩论打法（2 分钟立论 + 3 分钟结辩）

1. **立论三步**：定义边界 → 给判准 → 2–3 个论点（每个「观点 + 机制 + 例子」）。
2. **自由辩论三招**：要定义（对方的概念是否偷换）、要成本（好处谁拿、成本谁付）、
   极端化反例（按对方逻辑推下去会出现荒谬结论）。
3. **结辩四段**：承认对方一个合理点 → 指出其前提不成立（2 点）→ 回到我方判准（2 点）
   → 一句价值升华。
4. **组内纪律**：开场 2 分钟分工；绝不内讧；队友说错用「我补充一下」接；给队友递话。

### 8.2 高频辩题的正反方切入点

**① 是否应该取消无卡取款**（建设银行浙江分行，2025）

| 正方：应取消 | 反方：应保留 |
|---|---|
| 安全：无卡取款是电诈资金转移的高频通道，链条长、追损难 | 普惠：老人、境外来华人士、手机没电/丢失时，这是唯一应急通道 |
| 成本：设备改造与运维成本高，使用频次低 | 体验：免带卡、免排队，是基础服务能力 |
| 替代：手机银行转账 + 扫码支付已覆盖绝大多数场景 | 技术可控：限额 + 人脸 + 短信验证 + 延时到账可把风险压到可接受 |
| **陷阱**：不要把「取消无卡取款」说成「取消现金」 | **陷阱**：不要把「安全」说成「绝对零风险」 |

**② 电子竞技是否应该纳入奥运会**（招行总行，4v4）

| 正方：应该 | 反方：不应该 |
|---|---|
| 触达年轻人，奥运需要年轻化 | 奥运核心是身体运动与普世价值 |
| 入奥带来规范化（反兴奋剂、公平竞赛、版权治理） | 游戏版权属商业公司，规则可由厂商单方修改，与奥运「中立、稳定」冲突 |
| 产业与就业价值；已有亚运会先例 | 项目生命周期短，奥运需要长期稳定项目 |
| **判准**：奥运的门槛是「体育性」还是「青年影响力」 | **判准**：谁来定义「体育」 |

**③ 梦想是否会被现实打败**（招行总行，同场另一组）

- 正方（会）：资源约束是硬约束；「打败」不是放弃，而是被迫修正；大多数人的梦想确实会被调整。
- 反方（不会）：梦想可以被分解为可执行目标；现实改变的是**路径**不是**方向**；
  对方把「调整」偷换成了「打败」。
- **打法**：价值题不要站极端，用「定义 + 条件」取胜——「在什么条件下会，在什么条件下不会」。

**④ 应届生初期：优先高薪，还是优先有发展潜力的平台**（招行广州分行，2025）

| 高薪 | 平台 |
|---|---|
| 薪资是市场对你能力的定价信号 | 初期最重要的是能力复利与平台资源（项目/导师/客户） |
| 初期现金流约束真实存在（租房、还贷、家庭） | 高薪可能来自透支型岗位（高压销售/超长工时），长期折价 |
| 高薪平台往往也是高要求平台，倒逼成长 | 平台决定你下一份工作的**选择权** |
| 第一份薪资是后续跳槽的锚点 | 30 岁前看收入曲线**斜率**，不看起点 |
| **金句**：「第一份工作买的不是工资，是未来的选择权。」（反方用） | **金句**：「高薪是结果，平台是原因。」 |

**⑤ 年轻人节假日去寺庙旅游，本质是逃避还是疗愈**（民生银行西安分行）

- 逃避：短期情绪回避，不解决真实问题；消费主义包装的「伪治愈」；跟风属性强于真实需求。
- 疗愈：低成本的注意力切换与心理缓冲；精神文化需求的正当表达；
  「疗愈」本身就是一种应对机制，不必病理化。
- **打法**：区分「逃避行为」和「逃避人格」——偶发的调节不等于人格性逃避。

**⑥ 未来银行网点会不会消失**（杭州联合银行）

- 会消失：离柜率极高、现金与柜面业务萎缩；租金与人力成本不可逆；年轻客群全线上。
- 不会：复杂业务与高净值客户需要面对面信任；适老化与普惠的物理可达性；
  监管与现金服务义务；网点正在转型为「咨询/财富中心」。
- **高分结论**：不是消失，是**功能重构 + 数量优化**。谁先说出这句话，谁就像「有判断的人」。

**⑦ 银行应与企业合作，还是与社会服务部门合作**（苏州银行，开放银行背景，6v6）

- 企业端：场景与数据在产业侧，B 端嵌入带来结算、融资、供应链金融；收益可量化。
- 社会服务端（政务/医疗/教育）：高频刚需、获客成本低；政策导向与 ESG；数据合规更可控。
- **打法**：不选边，先定「开放银行的目标是场景触达 + 数据合规」，再给优先级条件。

**⑧ 短视频平台对知识传播利大于弊还是弊大于利**（工商银行长春分行）

- 利大于弊：降低门槛与触达；形式适配注意力；创作者激励。
- 弊大于利：碎片化导致「知道 ≠ 理解」；算法偏好情绪与极端，劣币驱逐良币；商业化催生伪知识。
- **打法**：加限定条件——「对科普入门利大于弊，对系统性学习弊大于利」。

**⑨ 职业内卷 vs 职业躺平，哪种更有利于长远发展**（招行深圳分行）

- 内卷方：竞争是资源筛选器；考核是动态的；但**要区分「有效努力」和「无效内卷」**。
- 躺平方：长期高压的 burnout 不可持续；客户经营靠判断力不靠工时；「适度躺平」= 拒绝无意义攀比。
- **金句**：「卷是生存的基本功，会休息才是长期主义。」

**⑩ 银行是否应该用 AI 客服全面替代人工** `【推断】`

- 支持：成本、7×24、标准化问题解决率；释放人力做高价值服务。
- 反对：复杂投诉与情绪安抚需要人；适老化；监管对「可解释、可追溯」的要求；
  一次误答的声誉成本极高。
- **高分结论**：替代「标准化问答」，不替代「信任与判断」；分层服务
  （AI 一线、人工二线、专家三线）。

## 9. 群面角色与话术（直接背）

**最优组合：框架提出者 + 时间管理者 + 汇总者。** 不要抢 Leader。

| 场景 | 话术 |
|---|---|
| 开场定框架 | 「我先抛一个框架，大家看看合不合适：这个题核心是 A 和 B 的取舍，所以我们可以先定评判标准，再用标准筛方案，最后定落地路径。时间 20 分钟，我建议 3 分钟定标准、10 分钟讨论、5 分钟收口、2 分钟检查。」 |
| 有人跑题 | 「这个点很重要，但我们先记下来，回到主线——我们还没确定判准。」 |
| 出现分歧 | 「我们的分歧其实不在结论，在判准。如果按 X 排会是 A，按 Y 排会是 B，题目问的是 ××，所以我建议按 X。」 |
| 抢话/冷场 | 「XX 刚才说的我认同，我补充一点……」／「我们还没听过 XX 的意见，要不要听一下？」 |
| 收口 | 「我复述一下我们的一致意见：1、2、3。有没有人不同意？没有的话建议由 XX 总结，我把要点整理给他。」 |
| 被质疑 | 「你这个角度我确实没想到，我调整一下：……」——先接住，再补充，不硬顶。 |

**群面后追问三连**（详见 `iv-005`）：谁最好/谁最差、为什么妥协、为什么发言少。
原则：**给结论但不伤人；承认事实但不认输；把「弱」落到可改进的行为上**。
